# stock-charts

Interactive stock charts with Plotly & yfinance: PE ratios, dividend yield, 25-year comparisons, sector analysis, DCF, PEG ratio

## Setup

```bash
pip install -r requirements.txt
cp .env.example .env   # then fill in your keys
```

## Environment Variables

```
  EDGAR_IDENTITY=your_edgar_identity_here
```
